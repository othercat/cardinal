# #5 从搜索结果排除文件与上级文件夹

[GitHub Issue #5](https://github.com/othercat/cardinal/issues/5)

在文件结果和文件事件的右键菜单中选择单个文件或指定层级的目录，将选择持久化到设置中的排除路径。核对本机与外置卷结果、父子路径的边界、撤销与重启，并评估 macOS 15 上停用 Spotlight 卷索引的影响。[总管 #1](issue-01-overall-management.md)

基线为 `master` 的 `25a53416cdffa57c5b6205f78af33482df5b58b1`。期望修改排除规则时保持其余已建索引可用。Spotlight 评估使用只读状态和 Apple 文档。

## r7 实现

- 文件与事件菜单都以实际点到的路径生成操作。排除上级目录的子菜单从直接父目录列到监控范围边界。菜单显示完整路径，遇到换行或尾部空格时在偏好设置按引号转义，保存后能恢复原名。原有复制、打开等操作保留多选语义。
- 同一监控根的完整本机索引按路径增删节点，已索引的无关文件继续可查。更深层的显式包含继续生效。撤销排除只枚举重新纳入的范围，正常退出或中断恢复保留可重放游标。首次建库尚未完成、或更换了监控根时，会按新配置流式扫描。
- 移动卷的规则按卷身份和卷内路径持久化。在缓存的节点树上排除后再排序和分页。清除规则可从原缓存立即恢复，支持离线卷及重新挂载。
- 本机以 `mdutil -s /` 确认 Spotlight 索引已启用。按卷开关可由 macOS 管理，通常需要管理员权限。本版排除菜单只管理 Cardinal。影响范围与系统设置入口见[使用说明](../docs/apple-silicon-search.md#spotlight-对文件名搜索的影响)。

## 验证

M1 Pro、macOS 15.7.7。本次根 Rust workspace 1,825 项通过，Tauri 默认 50 项通过。单独启用的 HFS+ 和 APFS 映像测试通过，覆盖卷离线与改挂载点后的排除。前端通过 typecheck、311 项 Vitest 和生产构建。两套 Rust workspace 的 Clippy 均通过。

从 #2 的私有旧库复制只读测试快照，载入 8,649,106 项用时 9.039 秒。在已载入的索引上交替排除和撤销各五轮，排除 `/bin/ls` 的中位数为 5 微秒，撤销为 15 微秒。排除 `/bin` 共 38 项，中位数为 15 微秒，撤销为 161 微秒。逐轮核对了无关文件的节点 ID、恢复后的总数和事件游标。这组计时只覆盖 Rust 索引操作，大目录的耗时会随实际受影响的条目和磁盘读取量变化。两份测试快照在验证后的 SHA-256 一致。

在独立 bundle ID、独立配置和五个样本文件的 WKWebView 窗口中，通过 macOS 辅助功能 `AXShowMenu` 打开结果行的原生菜单，使用 `AXPress` 选择三级目录中的中间层。291 毫秒后两个子项从界面消失，同名前缀的兄弟目录仍然可见。精确排除文件后 388 毫秒更新，同名加 `.bak` 的文件保留。在偏好设置撤销该文件的排除后 45 毫秒恢复。正常退出并以新进程重开，加载了已有索引，保留的目录规则、文件结果及磁盘文件均复核通过。以上为五文件夹具的一次窗口观察，包含检测界面变化的等待时间。
